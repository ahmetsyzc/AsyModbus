# AsyModbus

AsyModbus is a web-based application developed with C#, ASP.NET Web Forms, ADO.NET, and Microsoft SQL Server.

The project is currently under development. Its main purpose is to improve my practical experience in web development, database operations, and structured application design.

## 🚀 Current Features

- User management
- User login and authentication
- Role-based user structure
- Session management
- Password management
- Profile image management
- SQL Server database integration
- Stored procedure-based database operations
- User input validation

## 🏗️ Project Structure

The project separates database operations, business logic, and web application components to create a more organized and maintainable structure.

Main components include:

- **AsyModbus** — Web application and user interface
- **BusinessLayer** — Business logic and database operations
- **SQL Server** — Database and stored procedures

## 🗄️ Database

The application uses Microsoft SQL Server.

Database operations are mainly handled with stored procedures for operations such as:

- Adding users
- Updating users
- Deleting users
- Listing users
- User authentication
- Password operations
- Role management

ADO.NET is used for communication between the application and SQL Server.
